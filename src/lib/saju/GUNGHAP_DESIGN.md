# 사주 궁합 설계 문서

## 목적
두 사람의 사주를 입력받아 일간 오행 관계, 일지 합충 관계, 오행 분포 상보성을 분석하여 보여준다.
사이트 톤 일치: 정보 제공 목적, 점술적 판단 없음, "좋다/나쁘다" 점수 없음.

---

## 이동 경로 (Navigation Flow)

### Flow A: 직접 접근
```
/gunghap 직접 방문
  → 두 사람 입력폼
  → 결과
```

### Flow B: 사주 계산기에서 이동
```
/saju-calculator → 계산 결과 → "궁합 계산하기 →" 클릭
  → /gunghap (Person A: localStorage에서 이전 사주 입력값 복원 제안)
  → "내 사주를 불러왔습니다. 수정하거나 상대방 정보를 입력하세요."
  → 결과
```

**localStorage pre-fill 방식:**
- saju-calculator에서 계산 버튼 클릭 시 → SajuInput을 localStorage에 저장 (key: `saju_last_input`)
- /gunghap 로드 시 → localStorage에 값 있으면 Person A에 자동 복원 + 안내 메시지

### Flow C: 결과 → 재계산
```
/gunghap 결과 화면 → 입력값 수정 → 다시 계산
```

## 핵심 계산 로직 (compare.ts)

### 1. 일간 오행 관계
```
상생(相生) 순환: 목→화→토→금→수→목
  - A가 B를 생해줌: A의 오행이 B의 오행을 생함 (예: A=목, B=화)
  - B가 A를 생해줌: 역방향
  
상극(相剋) 순환: 목→토→수→화→금→목
  - A가 B를 극함
  - B가 A를 극함
  
비화(比和): 같은 오행 → 동등한 에너지

반응 텍스트 예시 (score 없이 관계 설명만):
  - 생해주는 관계: "[A 오행]이 [B 오행]을 북돋아주는 관계입니다"
  - 극하는 관계: "[A 오행]이 [B 오행]을 견제하는 관계입니다. 서로 긴장감을 만들기도 합니다"
  - 비화: "같은 [오행] 기운을 가진 두 사람입니다. 공명하거나 경쟁할 수 있습니다"
```

### 2. 일지 합충 관계
```
6합(六合): 서로 끌어당기는 관계
  자(0)-축(1), 인(2)-해(11), 묘(3)-술(10), 진(4)-유(9), 사(5)-신(8), 오(6)-미(7)

충(冲): 정반대 긴장 관계
  자(0)-오(6), 축(1)-미(7), 인(2)-신(8), 묘(3)-유(9), 진(4)-술(10), 사(5)-해(11)

삼합(三合) 부분 합: 두 사람이 같은 삼합에 속할 때
  인(2)-오(6)-술(10): 화 삼합
  신(8)-자(0)-진(4): 수 삼합
  해(11)-묘(3)-미(7): 목 삼합
  사(5)-유(9)-축(1): 금 삼합

중립: 위 관계 어디에도 해당 없음
```

### 3. 오행 상보성
```
A의 부족한 오행(0개)을 B가 가지고 있으면 → "상호 보완" 언급
A/B 오행 분포 나란히 비교 차트 (듀얼 바)
```

## 페이지 레이아웃

### 입력 영역
```
┌──────────────────────────────────────────┐
│  사주 궁합                                 │
│  두 사람의 생년월일시를 입력하세요           │
│                                           │
│  ┌────────────────────────────────┐      │
│  │ 나 (첫 번째 사람)               │      │
│  │  양력|음력  연도/월/일  시간     │      │
│  └────────────────────────────────┘      │
│  [내 사주 불러오기] (localStorage 있을 때) │
│                                           │
│  ┌────────────────────────────────┐      │
│  │ 상대방 (두 번째 사람)            │      │
│  │  양력|음력  연도/월/일  시간     │      │
│  └────────────────────────────────┘      │
│                                           │
│  [  궁합 계산하기  ]                       │
└──────────────────────────────────────────┘
```

데스크탑: 두 입력폼 2열 나란히 (gap between)
모바일: 위아래 스택

### 결과 영역
```
1. 두 사람 사주 나란히
   ┌─────────────┬─────────────┐
   │  나          │  상대방      │
   │  년주 월주    │  년주 월주   │
   │  일주 시주    │  일주 시주   │
   └─────────────┴─────────────┘
   모바일: 탭 전환 (나 / 상대방) 또는 스크롤

2. 일간 오행 관계 카드
   壬(수)  ↔  丁(화)
   [수극화] 설명 텍스트

3. 일지 관계 카드
   午(말)  ↔  亥(돼지)
   [인해합] 설명 텍스트

4. 오행 분포 비교
   목 ████░  나:2  vs  ██░░░  상대:1
   화 ...

5. 안내 문구
   "궁합 해석은 일주 외에도 전체 8자의 관계를 함께 살펴보는 것이 중요합니다..."
```

## 현재 네비게이션 문제점

1. **모바일**: 햄버거 열면 카테고리 10개 → 스크롤 필요 → "도구" 섹션 눈에 안 띔
2. **데스크탑**: 10개 카테고리 + 도구 드롭다운 = 내비가 좁은 화면에서 줄 바꿈
3. **사주→궁합 이동**: 결과 하단 링크만 있어 눈에 안 띔

### 개선안 A: 현행 유지
- 큰 변경 없이 모바일에서 도구 섹션 앞으로 이동

### 개선안 B: 헤더 간소화
- 카테고리는 "콘텐츠 ▼" 드롭다운으로 통합
- 나머지 슬롯: [콘텐츠 ▼] [도구 ▼]
- 더 깔끔하지만 카테고리 접근성 낮아짐

### 개선안 C: /tools 랜딩 페이지
- /tools 페이지에 모든 도구 카드 모음
- 헤더에 "도구" 단일 링크 → /tools
- SEO 이점, 도구 허브 역할

## 색상 / 시각 언어 일관성 이슈

현재:
- 타로 뽑기: 보라색 (#6B2D5E)
- 사주/궁합: --color-accent (황갈색 #8B6914)
- 꿈검색: 초록 (#4A6741)

헤더 도구 드롭다운은 --color-accent 사용 중.
각 도구 페이지의 카테고리 색상이 제각각임.
→ 도구 섹션 전체를 --color-accent로 통일할지, 각 도구별 고유 색 유지할지 결정 필요.
